# ============================================================
# Dependency Confusion — Internal Package Name Patterns
# ============================================================

# ---- Discovery Techniques ----
# 1. Check package.json, requirements.txt, build.gradle, pom.xml
# 2. Check JavaScript bundle source maps for internal imports
# 3. Search GitHub for: org:"COMPANY" filename:package.json
# 4. Search npm/pypi for company name prefix packages

# ---- Detection via Error Messages ----
# npm install → "Can't find package @company/utils" → try to publish it
# pip install → "No matching distribution found for company-internal"

# ---- Malicious Package Upload Strategy ----
# 1. Identify internal package name from leaked source/config
# 2. Register package on public registry with HIGHER version number
# 3. Add install script (postinstall) to exfiltrate environment
